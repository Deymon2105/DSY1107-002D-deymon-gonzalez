# DevLog · Semana 03

## Objetivo
Aprender a configurar y desplegar un API Manager en AWS, y configurar CORS para la comunicación entre diferentes servicios.

## Avance
- Desarrollé la actividad 1.1.1, donde configuré un API Manager con el servicio de "API Gateway" dentro de AWS. Luego desplegué el servicio y ejecuté pruebas con Postman para verificar su funcionamiento. 
- Desarrollé la actividad 1.1.4 donde se configuró CORS dentro del servicio del API Gateway para permitir comunicación entre el Cliente y el Servidor.
- Desarrollé la actividad 1.2.3 en donde se tenía que configurar un Tenant dentro de Azure.

## Bloqueo
No logré entender del todo lo que era un Tenant, cuál es su función y de qué nos sirve crearlo en nuestras aplicaciones. Además, no pude configurar el Tenant en Azure por problemas en la región elegida al momento de crearlo.

## Aprendizaje
Logré entender que en vez de configurar un API Manager en nuestro código directamente y desplegarlo, podemos aprovechar el servicio de API Gateway que nos ofrece AWS, lo que nos permite configurar las APIs de los servicios, versionado, CORS, etc.
