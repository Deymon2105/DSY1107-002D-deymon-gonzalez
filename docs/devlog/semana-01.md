# DevLog · Semana 01

## Objetivo
Esta semana quería retroalimentar todo el tema FullStack que habíamos visto durante el semestre anterior y lograr aprender cómo se gestiona realmente una API Gateway más en profundidad.

## Avance
- Desarrollar un diagnóstico a manera de retroalimentación.
- Estudiar la teoría detrás de lo que son las APIs, incluyendo HTTP, REST, Gateway y Management, así como el versionado, CORS, etc.
- Desarrollar el lab 1 donde entendimos en código cómo funciona una API Gateway, cómo conecta frontend y backend, cómo se gestiona CORS, y realizamos pruebas con Postman para entender cómo funciona el versionado de APIs.

## Bloqueo
Me costó entender cómo se gestionaba la API Gateway en código y cómo debía ir cambiando el versionado de APIs cuando íbamos haciendo cambios.

## Aprendizaje
Entendí que con la API Gateway podemos lograr la conexión entre el cliente y los servicios del backend de manera eficiente; podemos controlar rutas, rate limiting, políticas comunes y CORS para poder enviar solicitudes desde distintos orígenes. Con el API Management podemos gestionar todo el ciclo de vida completo.

## Siguiente
Aprender cómo funciona una correcta autenticación y cómo podemos aplicarla en nuestras aplicaciones.
